# 🚀 Asteroids  

Um jogo inspirado no clássico *Asteroids*, desenvolvido em **Pygame**, um projeto do curso Boot.Dev, onde o jogador controla uma nave e deve destruir os asteroides para sobreviver.  

## 🎮 Como Jogar  
- 🕹️ Use as **setas do teclado** para mover a nave  
- 🔫 Pressione **espaço** para atirar nos asteroides  
- ⚠️ Evite colisões com os asteroides para não perder vidas  

## 📦 Tecnologias Utilizadas  
- **Python**  
- **Pygame**  

## 📥 Como Instalar e Rodar  
1. **Clone o repositório**  
   ```bash
   git clone https://github.com/marianaeslan/asteroids.git
2. **Instale o Pygame**
   ```bash
   pip install pygame
3. **Execute o jogo**
  ```bash
  python main.py
