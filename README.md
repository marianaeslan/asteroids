# 🚀 Asteroids Game  

A **classic arcade-style space shooter** built with **Pygame**. Navigate through space, **destroy asteroids**, and survive as long as possible!  

![Asteroids Preview](https://github.com/marianaeslan/asteroids/blob/main/ast.png?raw=true)

## 🎮 Features  
✅ **Player-controlled spaceship** with smooth movement.  
✅ **Asteroids with random movement and different sizes** for an engaging challenge.  
✅ **Projectile shooting mechanics** to destroy asteroids.  
✅ **Collision detection system** to handle spaceship-asteroid interactions.  
✅ **Score tracking** based on destroyed asteroids.  
✅ **Retro-inspired design** for a nostalgic arcade experience.  

## 🛠️ Technologies Used  
The project was built using:  
- **Python** - Main programming language.  
- **Pygame** - Game development library for graphics and game logic.  

## 🎯 How to Play  
1. **Clone the repository**  
   ```bash
   git clone https://github.com/marianaeslan/asteroids.git
   ```

2.	**Navigate to the project folder**
      ```bash
      cd asteroids
      ```
3.	**Install dependencies**
      ```bash
      pip install pygame
      ```
4.	**Run the game**
      ```bash
      python main.py
      ```

## Controls
	•	Arrow Keys → Move the spaceship
	•	Spacebar → Shoot projectiles
